# TwinCamCaptureFor3D

同じWebカメラを二つPCに接続して、同時に描画品から縦横の位置を手動で合わせて  
同時に画像・動画として保存し、立体視用の素材を作るソフト。  


開発環境  
VSCODE  
C#　.NET10.0  
外部ライブラリ：OpenCvSarp、OpenCV  

WPFプロジェクト作成とライブラリ追加コマンド  
dotnet new wpf -f net10.0  
dotnet add package OpenCvSharp4  
dotnet add package OpenCvSharp4.runtime.win  
dotnet add package OpenCvSharp4.WpfExtensions
